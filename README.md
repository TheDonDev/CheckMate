# CheckMateApp

CheckMate is a mobile application designed to streamline student class attendance management in universities. Built with Flutter (Dart) for the frontend and Node.js for the backend, CheckMate provides a user-friendly and efficient solution for both lecturers and students to manage attendance digitally.
